# squonk2-jobs

An **umbrella repository** for the Squonk2 Data Manager **Job** ecosystem.
It gathers every Job-related repository together as a git submodule and is
the **authoritative home of all Job documentation**.

## Documentation

**Start here: [docs/README.md](docs/README.md)** — including the
[Getting Started guide](docs/getting-started.md) for anyone wanting to
write their own Jobs.

Documentation lives *here*; the other repositories enforce or follow it and
do not duplicate it.

## Cloning

```bash
git clone --recurse-submodules git@github.com:InformaticsMatters/squonk2-jobs.git
```

The submodules are catalogued in [docs/repositories.md](docs/repositories.md).
